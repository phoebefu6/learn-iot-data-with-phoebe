# Learn IoT & Industrial Data with Phoebe

Sixteen 45-minute sessions on what changes when the row is written by a sensor instead of a person.
Six leader sessions: sensors that drift, data that goes missing exactly when conditions are worst,
costs that are not symmetric, the home as a sensor network, why the warehouse playbook breaks, and
a transfer map of what a conventional data team carries over, must learn and must unlearn. Ten
practitioner sessions on real public rows from NASA's C-MAPSS turbofan simulation (FD001), from
channel triage and a health index to remaining useful life, planted missing-not-at-random dropout,
the asymmetric PHM08 score, an edge-or-cloud budget and smart-meter occupancy inference, ending in
a bench that runs the whole ladder in the browser.

- Open `index.html` in a browser; every page is static HTML with inline SVG.
- The engine is `assets/iot-live.js` (seeded, self-testing on load); `materials/iot_reference.py`
  agrees with it exactly on every canon number.
- Data: A. Saxena and K. Goebel (2008), "Turbofan Engine Degradation Simulation Data Set", NASA
  Prognostics Data Repository, NASA Ames Research Center. Simulated degradation, not real engines.
  Household and edge cases are constructed.

By Phoebe Fu.
